# Gestion des dépenses

Une application web simple et intuitive permettant de suivre et gérer ses dépenses quotidiennes en FCFA.

## Fonctionnalités
- Ajout d'une dépense (titre, montant, catégorie)
- Filtrage des dépenses par catégorie (Transport, Alimentation, Scolarité, Autres)
- Calcul automatique du total des dépenses affichées
- Sauvegarde locale automatique dans le navigateur (`localStorage`)
- Suppression d'une dépense

## Technologies utilisées
- **TypeScript**
- **Vite**
- **HTML5 & CSS3**
